# User Creation Lab

## Objective

Create a new user in Microsoft Entra ID and assign administrative permissions.

## Environment

- Microsoft Entra ID
- Test Tenant
- Web Admin Portal

## Steps Performed

1. Opened Microsoft Entra Admin Center.
2. Navigated to Users.
3. Selected New User.
4. Created user "Lab Admin".
5. Assigned Global Administrator role.
6. Verified successful creation.

## Result

User account was created successfully and administrative privileges were assigned.

## Skills Learned

- User Management
- Role-Based Access Control (RBAC)
- Microsoft Entra ID Administration
- Identity and Access Management
